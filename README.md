# Refrigeration System ML Prediction

## Objective
Predict refrigeration-system temperature response under
variable ambient operating conditions using machine learning.

## Inputs
- Ambient Temperature
- Power
- P1
- P2

## Outputs
- T5 Dry-Bulb Temperature
- T6 Wet-Bulb Temperature
- T7 Dry-Bulb Temperature
- T8 Wet-Bulb Temperature

## Models Compared
- Random Forest
- Extra Trees
- Gradient Boosting
- SVR
- Polynomial Ridge

## Final Model
Polynomial Ridge Regression

## Validation
Temperature-grouped cross-validation
